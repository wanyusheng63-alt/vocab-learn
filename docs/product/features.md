# VocabLearn - 单词记忆学习平台

## 产品概述
一个专业的英语单词深度解析学习工具，通过词根拆解、逻辑推理、用法对比等多维度帮助用户建立对单词的深刻理解，而非死记硬背。

## 核心功能

### 1. 单词列表浏览
- 网格卡片式布局展示所有单词
- 每个单词卡片显示单词本身和音标
- 点击卡片进入详细学习页
- 支持快速搜索和筛选

### 2. 单词深度解析（详情页核心）
每个单词包含以下解析维度：
- **词根拆解**：拆分为词根+词缀，解释词源和构词逻辑
- **底层逻辑**：阐述单词的本质含义和因果关系
- **核心用法**：列举典型使用场景和搭配
- **词义辨析**：与近义词的区别对比
- **记忆方式**：提供多种记忆技巧
- **常见误区**：指出易错用法
- **一句话总结**：精炼的核心定义

### 3. 发音学习
- 集成英美双发音
- 一键播放单词读音
- 音标显示

## 页面结构

### 首页 - 单词列表
- Hero区域：品牌标语 + 学习进度概览
- 单词网格：3列响应式布局
- 搜索栏：顶部固定搜索框
- 统计信息：总单词数、已学习数

### 详情页 - 单词解析
- 顶部：单词 + 音标 + 发音按钮
- 主体：7个解析卡片模块
  - 词根拆解（高亮显示）
  - 底层逻辑
  - 核心用法（带例句）
  - 词义辨析（对比表格）
  - 记忆方式
  - 常见误区（警示样式）
  - 一句话总结（强调框）
- 底部：上一词/下一词导航

## 设计风格

### 视觉方向
- **风格定位**：教育感、专注、清晰、温暖
- **色调**：温暖的米白底色 + 深蓝/靛蓝强调色（学习感）+ 橙/黄点缀（活力）
- **字体**：标题使用衬线字体增加文化感，正文使用无衬线保证可读性
- **布局**：卡片式模块化设计，信息层次清晰

### 动效要求
- 页面切换：滑动过渡
- 卡片悬停：轻微上浮 + 阴影加深
- 内容展开：平滑高度动画
- 按钮交互：涟漪效果

## 用户场景

1. **日常学习**：用户每天浏览5-10个单词，深度学习而非浅尝辄止
2. **考前复习**：快速回顾单词的核心逻辑和易错点
3. **词根探索**：通过词根关联记忆一组相关词汇
